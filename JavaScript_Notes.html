What is a function?

  • In math, function = rule that generates takes an input & generates an output
  • Programming = A reuseable piece of code used to perform a task (ie. like a variable)
  • variable = used to save a value
  • function = save a repetitive action

Creating our own functions

  • Why do we need to make functions/variables(?)? Reduce repetitive code & make it more readable; update/change value in one place instead of everywhere it goes; make data/values reuseable
  • Optimize code
  • A good function should be easily reuseable
  • There isn't a right or strict way to write functions
